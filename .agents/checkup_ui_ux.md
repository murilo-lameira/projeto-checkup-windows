# Agente: checkup_ui_ux (Designer & Frontend)

## Escopo e Responsabilidades
- Desenvolvimento de interface em `src/index.html`, `src/style.css` e manipulação de DOM em `src/renderer.js`.
- Guardião do Design System: Dark Glassmorphism (`rgba(24, 24, 27, 0.82)` com `backdrop-filter: blur(16px)`).
- Paleta Cobre (`.btn-copper`, tons de `#cf663f` a `#ff9364`) e acentos esmeralda/ciano (`#2dd4bf`).
- Gráficos circulares, barras e donuts com **ApexCharts**.
- Layout com CSS Grid de 6 colunas (`.dashboard-grid`).
- Microinterações, steppers verticais animados (`.pulse-border`) e toasts (`setStatus`).
